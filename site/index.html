Or download a release, or with Rust: cargo install --locked ruxguitar

Trouble installing?
Linux
The prebuilt player needs glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40 or later) and ALSA (libasound2). On an older system cargo install builds one that fits, with libasound2-dev installed. No sound under PulseAudio or PipeWire? Install pulseaudio-alsa or pipewire-alsa. File picker not opening? Install the XDG Desktop Portal for your desktop.
macOS
The player is not signed, so a copy downloaded in the browser is blocked on first launch. Allow it under System Settings, Privacy & Security, Open Anyway, or run xattr -d com.apple.quarantine ruxguitar. The curl command avoids this.
Windows
SmartScreen may warn about a downloaded copy: choose More info, then Run anyway. The PowerShell command avoids this. Windows 7 and 8 stop at v0.6.3.

Native Rust. No Electron, no Java.

Every Guitar Pro file

GP3, GP4 and GP5, plus the newer .gpx and .gp formats. Open them from the picker or drop them on the window.

Sound in the binary

A soundfont ships inside the executable, so playback works on a fresh machine. Point it at a bigger one when you want better tone.

Built for practice

Slow a passage to a quarter speed, solo the track you are learning, and let repeats and alternate endings play out on their own.
